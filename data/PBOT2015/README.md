# PBOT Puerto Rico (Caquetá) — cartografía de formulación 2015

Paquete geoespacial preparado a partir del archivo fuente `Consolidado Cartografias Formulacion.zip` aportado para SIGOber-Rural.

## Capas web procesadas
- `ZONIFICACION_DE_USO_DEL_SUELO_RURAL_UGOT.geojson` — 6 polígonos
- `ZONIFICACION_DE_USO_DEL_SUELO_RURAL_PROTECCION.geojson` — 3 polígonos
- `PERIMETRO_URBANO_Y_DE_EXPANSION_PERIMETRO.geojson` — 7 polígonos
- `TRATAMIENTOS_URBANOS_TRATAMIENTOS_URB.geojson` — 5 polígonos
- `ZONAS_HOMOGENEAS_URBANO_ZONAS_HOMOGENEAS.geojson` — 16 polígonos
- `PUNTOS_EXPANSION_URBANO_PUNTOS_EXPANSION.geojson` — 54 puntos
- `MANZANAS_INSPECCIONES_MANZANAS.geojson` — 95 polígonos

Todos los GeoJSON de visualización están en EPSG:4326. Se conservan los paquetes SHP originales fuera de GitHub como fuente de procedencia.

## Regla de vigencia
Estas capas representan **formulación PBOT 2015**. No deben presentarse como la modificación excepcional de 2023 hasta contrastarlas con el Acuerdo 128 de 2023 y su cartografía adoptada.

## Observación
El paquete original contiene `Planes_parciales_urbano_shp.zip`, pero el SHP no trae archivo DBF asociado; por ello no se incorpora todavía como capa web con atributos. Se mantiene como pendiente de revisión.
